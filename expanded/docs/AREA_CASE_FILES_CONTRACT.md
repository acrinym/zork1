# Area Case-File Contract

## Purpose

Regional case files summarize what this player has actually established about a place. They are not an objective encyclopedia of everything implemented in the game.

## Record lifecycle

1. **Absent** — no player-earned regional evidence exists.
2. **Partial** — the first earned evidence creates one physical case file.
3. **Evolving** — later discoveries add bounded evidence categories.
4. **Complete** — the region-specific contract is satisfied.
5. **Synthesized** — only after all five regional files are complete, one retrospective printout may appear.

A record never regresses because a live object later moves, but current-state claims remain clearly separated from retained historical evidence.

## Regional contracts

### White house

Uses established house use, Attic and Cellar thresholds, return cycles, collection evidence, and physical disturbance. The canonical trophy-case score remains authoritative.

### Forest

Uses direct visits to the three forest sectors and clearing, plus living evidence only when directly observed. It supplies no hidden route or undiscovered map.

### Flood Control Dam #3

Uses direct Dam/maintenance visits, diagnosed controls, interlock and bolt observations, actual gate cycling, leak activation, repair, and exact correspondence or printout when present. It does not print an unearned operating sequence.

### Hades ceremony

Uses direct place and spirit evidence, the damaged book record, observed resonance and paired-light stages, wrong-order evidence, mirror variation, and canonical completion. It never names an unobserved next action.

### Underground

Cross-indexes the Cellar threshold, player-specific troll/cyclops/thief dossiers, and completed Dam and Hades files. Missing actor evidence remains missing.

## Synthesis boundary

`AREA-SYNTHESIS` is retrospective explanation, not a completion meter. It appears only after all required regional completion bits exist.

Reading it cannot:

- alter score;
- move or duplicate objects;
- open routes;
- change actors or combat;
- advance timers;
- repair evidence;
- merge separate expeditions;
- expose an unseen solution.

## Persistence

Evidence categories, completion bits, filing state, and exact physical custody are ordinary native-save state. Qualification must remove them deliberately and prove `RESTORE` returns them without a repair pass.
