# Archival Transcript and Playback Contract

## Authority

Canonical Zork state remains the only source of truth. Playback consumes qualified House, Dam, Hades, NPC, and area evidence; it does not become another controller.

## Event model

A playback event must be:

1. consequential rather than routine;
2. supported by an existing canonical flag or qualified archive state;
3. unique within the expedition;
4. safe to summarize without exposing an unseen solution;
5. representable inside the fixed twelve-event sequence.

## Presentation

The line printer uses normalized action labels and verified outcomes. The cassette uses original contextual narration, speaker labels, pauses, hiss, and environmental cues. Scene cards navigate the same bounded evidence by incident, actor, place, and first-capture chronology.

The forensic strip is bounded evidence metadata, not universal surveillance or a raw parser transcript.

## Integrity

For every playback read or review:

- the action is classified as non-turning by Shadow threat machinery;
- `CLOCK-WAIT` is asserted;
- `HERE`, `SCORE`, `SHADOW-SELF-FIRE`, actor locations, `P-IT-OBJECT`, and record location are checked;
- the prior non-playback parser pronoun is restored;
- failure is visible rather than silently repaired.

## Explicit exclusions

Release `1227` does not provide:

- unbounded command logging;
- verbatim reconstruction of missing dialogue;
- actor animation or simulation;
- route, puzzle, object, score, timer, or combat changes;
- merged histories from mutually exclusive expeditions;
- a modern media browser;
- sub-beads or a second planning hierarchy.
