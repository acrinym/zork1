# Flathead Fair games, competitions, and records

**Status:** DESIGNING

## Midway game families

Candidates include ring toss, bottle knockdown, darts, target shooting, strength testing, horseshoes, beanbag/toss games, shell/guessing games, timed puzzles, races, memory games, and fair-specific mechanical contraptions.

## Mechanic diversity law

Do not hide the same `RANDOM(100)` roll beneath twelve different descriptions.

Games should vary in what matters:

- observation;
- equipment;
- preparation;
- timing;
- player knowledge;
- physical condition where an existing authority supports it;
- genuine chance;
- opponent behavior.

## Records

The fair may maintain records such as:

- fishing weight/length;
- strength score;
- target score;
- race winners;
- food/agricultural contests;
- unusual annual competitions.

Records should persist when the fair returns if broader persistence supports the elapsed time.

## Anti-grind rule

First-time achievements, records, quests, or difficult wins should matter more than farming an easy booth hundreds of times. Prize economy must not reward repetitive mechanical exploitation as the optimal strategy.

## Fairness

Games can be unfair in-character only when the unfairness is itself discoverable and actionable. A rigged game can be a story; hidden author cheating is not.
