# Release 1272 — Shadowgate-Style Macrostructure, Original Zork Region

Release 1272 builds the **Ashglass Observatory**, a 24-room original Zork region south of the Great Canyon / Forest edge. It uses the preceding design language as one coherent adventure rather than as disconnected demonstrations.

## Region grammar

- two outside approaches converge on the same observatory complex;
- a physical windthrow route can be cut with the canonical axe;
- an old canyon milestone can reveal a second maintenance descent through physical manipulation or previously learned air-passage notation;
- a black archive slate teaches the region-specific `FOCUS` operation, turning learned knowledge into parser capability without creating a spell list;
- a lens alignment reveals hidden architecture;
- a second old air-passage marking and soot seam create a service-vent bypass when interpreted/examined honestly;
- cistern spray physically waterlogs carried ritual candles, allowing the already-authored stilling ward to matter if the Adventurer genuinely knows it;
- a damaged lower ladder requires real bright working light rather than a binary lit-room flag;
- a huge rook controls a stair by attention and physical position, and can be lured briefly by several already-real shiny objects;
- the rook can expose an optional brass observatory token that is not required for completion;
- a three-notch brake and counterweight system is physically legible and genuinely lethal if released unarrested;
- an old ashglass bridge reacts to actual carried weight, gives one persistent fracture warning, then can fail lethally if the same overloaded choice is repeated;
- glass bridge, counterweight lift, and opened service tunnel converge on the vault antechamber, so there is no single corridor-shaped solution.

## Authority boundaries

This train adds no generic region engine, climate simulator, creature AI brain, puzzle registry, universal secret-door framework, or inventory recipe matrix. `ashglass_observatory.zil` owns only Ashglass geography and mechanism state. Existing authorities remain authoritative for carried weight, light condition, candle wetness, the learned stilling ward, old-script / air-passage knowledge, canonical axe identity, and death/recovery.
