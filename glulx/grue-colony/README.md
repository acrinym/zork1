# Release 1256 — Grue Ecology & Colony Reveal

Release 1256 keeps canonical grue darkness danger intact while adding one authored ecology experiment in the mine.

- The optional mine dead end contains targetable fissures with local reveal state stored on the fissures themselves.
- Ordinary lantern light keeps the room usable and yields only plural sounds/evidence at the edge of visibility.
- Bringing the permanent flaming ivory torch forces a signature retreat through multiple fissures and reveals a colony.
- After the reveal, GRUE/FISSURES examination and listening report ecology evidence without ever making a grue an ordinary visible combat actor.
- Canonical dark-room death/noise paths in `gverbs.zil` are untouched.
- No new VM global, grue HP/stat block, monster-attractor engine, or generic dark-room hive system is added.
