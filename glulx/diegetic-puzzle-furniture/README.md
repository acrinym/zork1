# Release 1274 — Environmental Mechanisms & Diegetic Puzzle Furniture

Release 1274 turns four prose-visible Ashglass irregularities into distinct persistent physical mechanisms. It follows the contract:

**notice an irregularity → examine it → learn a physical fact → manipulate the correct concrete detail → the environment changes**

## Authored mechanisms

1. **Ruined Scriptorium — captive index volume / pivot shelf.** One surviving shelf has a floor pivot and a suspiciously clean black index volume. Taking the volume reveals that it is captive; pulling it through its brass travel releases the shelf latch and opens a real east passage to the Broken Gallery.
2. **Ashglass Vault — proud mineral tray / false back.** Straight scrape marks show that one tray travels deeper rather than outward. Pushing it past the shelf line drops a shallow false back and reveals a persistent compartment containing a small bronze star-wheel. The wheel is an ordinary instrument part with no promised quest destiny.
3. **Bell Tower — weather regulator clock.** Dust and wear identify one clean index notch on a stopped hand. Pulling the chain before alignment locks the mechanism; turning the hand into the physical stop takes up slack, after which pulling the chain pivots the lower clock case and exposes a real maintenance recess.
4. **Low Cistern — pale brick / drain rod.** One dry clean brick has an abnormal mortar gap. Pushing it reveals the actual bronze pull rod. Pulling that rod diverts the main spillway and exposes a dry south ledge, bypassing the spray without rewriting the existing candle-wetness authority.

## Authority boundaries

There is no `SECRET_SWITCH`, generic furniture state machine, automatic noun promotion, universal hidden-door registry, arbitrary `USE X ON Y` matrix, or procedural mechanism framework. `diegetic_puzzle_furniture.zil` owns only six narrow facts for these four mechanisms. Existing Ashglass geography and candle wetness remain authoritative; Release 1274 only adds two persistent alternate physical routes and two persistent compartments.
