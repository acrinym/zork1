# Attic Area Case Files — Release 1226 Candidate

## Product boundary

Release `1226` extends the qualified Release `1225` archive with exact physical regional records for:

- the white house;
- the surrounding forest;
- Flood Control Dam #3;
- the Hades ceremony;
- the broader underground expedition;
- one retrospective synthesis printout.

The system is evidence-driven. A partial file may appear after the player earns the first relevant observation, but every unearned section remains explicitly missing, unresolved, or redacted.

## Completion is not a checklist

Each regional file has a bounded completion contract derived from existing canonical state and earlier qualified systems.

The archive never:

- tells the player the next puzzle step;
- exposes an undiscovered route;
- changes a mechanism, actor, object, timer, or room;
- grants score;
- fabricates paperwork or missing property;
- completes a case because the relevant content merely exists elsewhere in the game.

The synthesis printout appears only when all five regional files satisfy their own earned-evidence contracts. It explains relationships among already verified facts and remains retrospective.

## Physical records

- `AREA-HOUSE-01` — white house case file;
- `AREA-FOREST-02` — forest exploration case file;
- `AREA-DAM-03` — Flood Control Dam #3 case file;
- `AREA-HADES-04` — Hades ceremony case file;
- `AREA-UNDERGROUND-05` — underground expedition case file;
- `AREA-SYNTHESIS` — complete retrospective regional printout.

Every record is one exact object. Ordinary `READ`, `EXAMINE`, `TAKE`, `FILE`, `REVIEW`, `SHOW`, and `CROSSREF` behavior uses the existing Attic archive machinery.

## Evidence model

Case sections distinguish:

- discoveries;
- mechanisms actually observed;
- outcomes actually produced;
- exact physical documents;
- actors directly encountered;
- unresolved variations;
- complete retrospective synthesis.

Partial records retain gaps rather than converting absence into advice.

## Qualification route

The dedicated route proves:

1. no unearned Dam, Hades, or synthesis file appears during ordinary early-house play;
2. partial Dam and forest files expose redaction rather than solutions;
3. all five regional files can become complete from controlled canonical evidence;
4. synthesis appears only after every regional contract is complete;
5. filing moves one exact record into the existing steel cabinet;
6. reading and cross-referencing mutate no live world state;
7. native `SAVE`, deliberate corruption, and `RESTORE` recover exact evidence, completion bits, records, and custody without repair.
