## Completion is not a checklist

- tells the player the next puzzle step;
- exposes an undiscovered route;
- changes a mechanism, actor, object, timer, or room;
- grants score;
- fabricates paperwork or missing property;
- completes a case because the relevant content merely exists elsewhere in the game.

The synthesis printout appears only when all five regional files satisfy their own earned-evidence contracts. It explains relationships among already verified facts and remains retrospective.
