# Release 1273 — Living Biomes & Wilderness Expansion

Release 1273 grows the existing outdoor geography west of `FOREST-1` into two authored wilderness identities rather than generating more generic forest rooms.

## Western Backcountry

The canonical `FOREST-1` text already says westward travel would require a machete. Release 1273 makes that statement physical instead of leaving it as permanent map-edge prose.

A real old forester's machete is found at the Ashglass Observatory's outer court. It can be carried, dropped, stolen, lost, and used as an ordinary cutting tool. Cutting the exact western brush gate opens a persistent route into a nine-room backcountry of hemlock swales, beaver wetland, cold spring, fallen cedar, animal trail, moss ridge, and a warm-air notch.

The backcountry is not another maze. Wildlife creates readable geography: a beaver-maintained wetland provides a crossing and real water-state explanation; fox tracks expose an optional shortcut; changing vegetation and air temperature physically foreshadow the basin beyond.

## Warmrain Basin

Beyond the ridge is a thirteen-room enclosed rain forest whose climate is maintained by geothermal springs, deep topography, and constant warm mist. This makes the first wholly new Zork biome geographically strange but physically legible instead of placing a tropical jungle beside conifers with no explanation.

The basin is mechanically distinct through selected authored consequences rather than a universal climate model:

- dripping canopy can soak exposed ritual candles using the existing candle-wetness authority;
- root mats, mud, epiphytes, broadleaf canopy, warm pools, and moving water are concrete parser targets;
- leafcutter ants reveal a drier root route when observed, turning ecology into navigation without becoming a hint marker;
- harmless glass frogs, fruit bats, and other small life provide targetable sensory evidence instead of existing only as prose decoration;
- a large warm-water caiman controls one ford through real position and hunting behavior;
- the canonical dam silverfin can be sacrificed as one physical lure, moving the exact fish object rather than spawning bait;
- a fallen giant and vine route provide non-fish alternatives, so the predator is not a mandatory inventory lock;
- repeated reckless entry into the occupied ford can become an authored causal death only after the player has been physically warned.

## Boundaries

There is no biome generator, climate stat sheet, procedural vegetation, generic creature AI, random encounter table, universal scent/stealth meter, or generalized survival simulation. Each ecology interaction belongs to the actual place/creature/object involved.

The release expands new wilderness. It does not select or expand any Release 1275 slim existing locale, so the later Justin approval gate remains intact.
