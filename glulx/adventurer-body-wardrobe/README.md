# Release 1309 — Adventurer body, clothing, House wardrobe, and lived boundaries

Stages locked Release **1306**. Coupler: romance capstone first.

Clothes are objects. The House holds the wardrobe, dresser, basin, washroot, and the clothesline east of the house. Mara keeps her coat and one physical field ration when she chooses the House as a base. No GUI. No clothing RPG. No relationship meter.

Release 1309 also composes the new physical ownership surface with the already-shipped Mara relationship history instead of creating a parallel social system:

- `EXAMINE MARA` keeps Release 1306's repeated-looking boundary;
- the first attempt to take/remove Mara's coat states an explicit boundary;
- knowingly repeating that attempt can open the existing Release 1260 rupture;
- Mara's field ration is real property, can be taken when she is not physically there, can be noticed later from real custody, and can be returned;
- repeatedly ordering independently acting Mara to `WAIT` after she has made her own choice can become an autonomy-boundary rupture;
- these nonviolent ruptures set the same `MARA-SLOT-RUPTURE-OPEN` used by 1260/1306, so `KISS` and `STAY` respect them automatically;
- cause-specific dialogue does **not** falsely describe food, clothing, or autonomy violations as a physical attack;
- `APOLOGIZE TO MARA` remains acknowledgment, not reset. Actual space and corrected physical behavior are required before Mara can choose ordinary proximity again;
- old facts remain true after repair.

One accident or first ordinary boundary mistake is not automatically rupture. The product chain is intentionally authored as:

`action → explicit boundary → knowing repetition / serious violation → carried meaning → rupture → acknowledgment → actual space → changed behavior → possible repair`

The ordinary Zork journey remains fully playable without changing clothes, washing anything, stealing food, testing Mara's boundaries, or entering a relationship.
