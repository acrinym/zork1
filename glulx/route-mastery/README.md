# Release 1252 — Earned Sequence Breaks & Route Mastery

Release 1252 layers directly over the locked Release 1251 Cross-System Utility Mesh.
It does not add a generic shortcut system or a physics simulator. It promotes a few
already-real relationships into player-visible route mastery.

## Player-facing outcomes

### Great Canyon: one rope, one physical truth

Release 1236 already made `SECURE ROPE` physically place the real rope on the Great
Canyon rim. Release 1251 later taught the same rope to cinch cargo and operate across
authored vertical geography. Release 1252 joins those authorities instead of creating
a third canyon-rope state.

At Canyon View:

- `SECURE ROPE` remains valid;
- `TIE ROPE TO CANYON RIM` / `FASTEN ROPE TO RIM` reaches that same 1236 authority;
- a rope already cinched to the brown sack may use the canyon rim as its other real end;
- `LOWER SACK` stages that cargo on Rocky Ledge, not magically at Canyon Bottom;
- `PULL ROPE` / `RAISE ROPE` hauls the staged cargo back to Canyon View;
- the adventurer can follow the canonical climb to Rocky Ledge, free the sack there,
  then climb back later to recover the rope;
- untie narration distinguishes the cargo knot from the fixed canyon-rim knot.

No new rope global was added. The fixed end is still the physical Release 1236 fact:
the rope is actually in `LIVING-CANYON-EDGE`. The cargo end remains the Release 1251
sack state.

### White Cliffs: containers do not shrink boats

The canonical White Cliffs path is narrow enough to reject the inflated magic boat
and pass the folded/deflated boat. Release 1252 makes that geometry look through
carried containers. Putting an inflated boat inside a large container no longer
turns it into a smaller object for route checks.

`FOLD BOAT` and `COLLAPSE BOAT` are also recognized as natural language for the
canonical `DEFLATE` action. The canonical requirement that the boat be on the ground
before deflation remains intact.

## Boundaries

- no teleport verbs;
- no route-selection menu;
- no object-pair recipe matrix;
- no new universal rope engine;
- no magical rainbow anchoring;
- no change to the lethal result of removing a solid rainbow while standing on it;
- no change to canonical Great Canyon, rainbow, White Cliffs, boat, or river routes;
- no automatic puzzle completion or score award.

The product principle is simple: preparation can make existing geography more useful,
but the geography keeps its physical constraints.
